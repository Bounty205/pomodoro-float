# PomodoroFloat

Большой таймер «Помодоро» для macOS. Окно висит поверх всех окон, в том числе поверх полноэкранных приложений, и не занимает место в Dock.

- Режимы 25, 45 и 60 минут, переключаются кнопкой с длительностью. Для 25 минут перерыв 5 минут, для 45 минут 10, для 60 минут 15. Длинный перерыв после каждых четырёх отрезков: 15, 20 или 25 минут.
- Кнопки: режим, Старт/Пауза, Сброс (текущий отрезок), Дальше (пропустить), Выход.
- Окно почти прозрачное: видна только тонкая рамка, а цифры таймера полупрозрачные. Прозрачность цифр задаётся константой `digitAlpha` в `main.swift`.
- Окно можно перетащить за любое место. Таймер считает по системным часам, поэтому не сбивается, если Mac уснул.
- В конце отрезка звучит системный звук «Glass», а окно выходит вперёд.

## Сборка

Нужны Xcode Command Line Tools (`xcode-select --install`).

```bash
./build.sh
open PomodoroFloat.app
```

Приложение собирается без подписи Apple и работает только на вашем Mac. Чтобы закрыть, нажмите «Выход».

## Автозапуск

Системные настройки → Основные → Объекты входа → добавить `PomodoroFloat.app`.
